# Calup

Android-приложение для работы с FBS-заказами Wildberries и Ozon.

## Скачать

**[Скачать последнюю версию Calup](https://github.com/abdullaaliev/calup-releases/releases/latest)**

На странице выпуска выберите файл `calup-…apk`. Скачайте его на Android-телефон и подтвердите установку. Android может запросить разрешение установки из браузера или файлового менеджера. Не удаляйте уже установленное приложение перед обновлением.

После первой установки новые версии предлагаются внутри Calup: скачать APK → подтвердить системную установку. Ручная проверка доступна в «Подключения → Обновления Calup».

## Печать наклеек 58×40 по Wi-Fi

Если принтер уже виден в обычной печати телефона, выберите «Печать Android» после предпросмотра в Calup.

Если принтер подключён только по USB к компьютеру:

1. На Windows 10/11 x64 [скачайте Calup Print](https://github.com/abdullaaliev/calup-releases/releases/download/v0.2.3/CalupPrint-Windows-x64.zip), распакуйте ZIP и запустите `CalupPrint.exe`.
2. Выберите ваш уже настроенный Xprinter 58×40 и нажмите «Включить приём с телефона».
3. Подключите телефон и компьютер к одной сети; разрешите помощнику доступ в частной сети Windows.
4. В Calup откройте «Подключения → Печать стикеров → Настройка печати / инструкция → Принтер по USB к компьютеру Windows». Отсканируйте QR из окна помощника.
5. Проверьте связь и начните с одной тестовой наклейки 58×40. Оставьте флажок «Запускать вместе с Windows»: окно можно закрыть, помощник остаётся возле часов и запускается автоматически после входа в Windows. Компьютер должен быть включён и не спать.

Для обновления уже работающего помощника сначала выберите «Выход» в меню его значка возле часов, затем запустите новый EXE. Прежний принтер и ключ подключения сохраняются. Нажмите кнопку разрешения Wi-Fi и проверьте связь в Calup: новая версия умеет находить тот же компьютер при смене IP без нового QR, если локальная сеть разрешает такой поиск.

Драйвер принтера менять не нужно. Подробная инструкция находится в ZIP. На WB печать доступна после добавления в поставку, на Ozon — после сборки. Реальный размер и выход наклеек зависят от настроенной очереди Windows и принтера.

## Возможности

- WB и Ozon в отдельных разделах.
- Фото товаров, количество и общий список сбора со склада с галочками.
- Добавление новых заказов WB в поставку.
- Поиск заказа по этикетке, фото товара и камера ЧЗ на одном экране.
- Передача кодов маркировки в маркетплейсы и подготовка отгрузок.
- Светлая и тёмная темы, настраиваемые эффекты стекла.

Требуется Android 8.0 или новее. Ключи своего магазина пользователь вводит после установки. Отгрузку подтверждайте после подготовки товаров.

## Конфиденциальность

API-ключи и сохранённые коды хранятся зашифрованными на устройстве пользователя. Запросы маркетплейсам идут напрямую; владельцу репозитория ключи не отправляются. GitHub используется для проверки версии и скачивания APK. Здесь опубликованы установочные файлы; исходный код хранится отдельно.
